# HW3: SFT для function calling

В этом задании я дообучил `Qwen/Qwen2.5-0.5B-Instruct` на диалогах с функциями умного дома. Модель училась не только выбирать функцию и её аргументы, но и уточнять недостающие данные, делать несколько вызовов и продолжать диалог после результата функции.

После SFT `exact match` вырос с 0.55 до 0.90 на английской части теста и с 0.20 до 0.90 на русской. Ошибочные вызовы для гаража и комнаты `all`, которые встречались у исходной модели, после обучения пропали.

## Результаты

| Модель | Язык | Набор функций | Exact match |
|---|---|---:|---:|
| Base | EN | 0.750 | 0.550 |
| Base | RU | 0.750 | 0.200 |
| SFT | EN | **0.925** | **0.900** |
| SFT | RU | **0.950** | **0.900** |

`Набор функций` проверяет, что выбраны нужные функции, а `exact match` дополнительно требует правильные аргументы. Всего в тесте 60 примеров: 40 на английском и 20 на русском.

После второй эпохи validation loss почти перестал улучшаться, хотя training loss продолжил снижаться. Я отдельно проверил обучение на двух эпохах, но функциональная метрика оказалась хуже: `exact match` 0.825 EN / 0.75 RU. Поэтому в финальном варианте оставлены три эпохи.

Итоговый `eval_loss = 0.2690`, средняя token accuracy — 0.9303.

## Агентный цикл

`run_agent` повторяет цепочку «ответ модели → вызов функций → результат в истории», пока модель не вернёт обычный текст. В ноутбуке сохранены пять проверок:

1. один вызов функции;
2. два независимых вызова за один ход;
3. относительное изменение температуры через `get_room_state` и `set_temperature`;
4. обычный ответ без функции;
5. отказ на неподдерживаемый запрос.

Во всех пяти сценариях вызовы выполнены, результаты добавлены в историю, а состояние симулятора совпадает с командами.

## Структура папки

- `sft_function_calling_hw.ipynb` — заполненный и исполненный ноутбук со всеми выводами;
- `outputs/eval_results.csv` — итоговые метрики base и SFT-модели;
- `data/` — train, validation и test в JSONL;
- `smart_home.py` — функции и симулятор умного дома;
- `chat_ui.py` — интерактивный интерфейс для проверки агента.

Веса модели в репозиторий не добавлены. Для повторного запуска нужен GPU; версии основных библиотек зафиксированы в первой ячейке ноутбука.
